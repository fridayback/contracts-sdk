📌 修改目的与背景

上游合约仓库 cardano-plutus2aiken 的 msg-gpk-activate 分支（相对 alpha 分支）新增了三类跨链桥治理能力：

  • GPK 激活延迟（PendingGPK）：oracle 先预置 pending GPK（params[14]，CBOR 编码），24h 延迟后由 oracle 激活；admin 可立即生效并清 pending，防止 GPK 轮换被单点瞬间控制。
  • 跨链限额（CrossLimit）：params[15] 存 CBOR 编码的资产限额表，跨链转账受额度约束。
  • 暂停（halt）：params[16] HaltWorker / params[17] HaltStatus；haltworker 可 0→1 暂停桥，admin 可 1→0 恢复。

本分支在不冲击现有 SDK 框架的前提下（不改既有方法签名、不替换合约字节码 json），增量实现上述功能的 SDK 支持。
